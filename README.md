# Envelure Releases

This repository is the public release channel for `envelure`.

It contains release notes, checksums, install guidance, and binary release assets.

It does not contain the private source code repository.

## Purpose

- publish release artifacts without exposing source code
- provide a stable public location for release notes and checksums
- support future installer and auto-update flows

## Install and Update

Installation and update instructions will be published here alongside each release.

## Repository Layout

- `releases/` release manifests and per-version metadata
- `checksums/` published checksums for release assets
- GitHub Releases binary assets and notes

## Security

Only release artifacts intended for public distribution should be pushed here.
Do not publish source archives, internal build outputs, private debugging material, or CI secrets.
